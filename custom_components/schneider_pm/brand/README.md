# Brand images

These images identify the manufacturer of the meters supported by this
independent Home Assistant integration. This project is not affiliated with or
endorsed by Schneider Electric. Schneider Electric and its logos belong to
their respective owner; the repository's MIT license does not apply to them.

Source: inline SVG images in the mobile and desktop headers of the
[Schneider Electric website](https://www.se.com/ww/en/), retrieved 2026-10-06.
The source images carry this notice:

```text
SPDX-FileCopyrightText: © 2024 Schneider Electric
SPDX-License-Identifier: LicenseRef-Proprietary
```

The SVGs were rasterized with CairoSVG, preserving their shapes, original
colors and aspect ratios. PNG files were losslessly optimized with Pillow.

| Image | Dimensions |
| --- | --- |
| `icon.png` | 256 × 256 |
| `icon@2x.png` | 512 × 512 |
| `logo.png` | 654 × 192 |
| `logo@2x.png` | 1308 × 384 |

All images have transparent backgrounds. Home Assistant uses these local images
in both light and dark mode through its image fallback mechanism. No additional
manifest setting or submission to the Home Assistant brands repository is needed.
See the [Home Assistant brand image documentation](https://developers.home-assistant.io/docs/core/integration/brand_images/).
